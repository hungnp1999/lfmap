## 1. Yêu cầu chức năng

### FR-01 Mã lỗi chuẩn — Roadmap 0.2

- `ToolError(code, message, details=None)`; `code` thuộc `invalid_input`, `permission_denied`, `not_found`, `backend_unavailable`, `timeout`, `internal`.
- `details` mặc định `{}`; `str()` = `"<code>: <message>"`; `to_dict()` = `{"code","message","details"}`.
- Code: `core/errors.py` · Test: `test_errors.py`.

### FR-02 Khai báo operation — Roadmap 0.2

- `@operation("name")` gắn thuộc tính `__lfmap_operation__`, không bọc hàm.
- `Tool.operations()` trả `{name: OperationSpec}`; method phải nhận đúng 1 tham số (ngoài `self`) là Pydantic model và trả về Pydantic model, nếu không `TypeError` nêu tên method; trùng tên operation → `TypeError`.
- `description` = dòng đầu docstring.
- `Tool.health()` mặc định `{"ok": True}`.
- Code: `core/tool.py` (`operation`, `_spec`, `Tool.operations`) · Test: `test_tool.py`.

### FR-03 Gọi operation — Roadmap 0.2

- `invoke(tool, name, payload)`: tên không có → `ToolError("not_found")`; payload sai schema → `ToolError("invalid_input", details={"errors": [...]})`; đúng → trả Output model.
- `runtime.run_operation(entry, name, payload, variables=None)`: dựng `PermissionManager` từ manifest + biến từ config người dùng, tạo tool, gọi `invoke`.
- Code: `core/tool.py::invoke`, `core/runtime.py` · Test: `test_tool.py`, `test_cli.py`, `test_mcp_adapter.py`.

### FR-04 Manifest `lfmap.toml` — Roadmap 0.3

- Bảng `[plugin]` (bắt buộc): `id` khớp `^[a-z][a-z0-9-]*$`, `version` SemVer `X.Y.Z`, `name`, `description`, `license`, `entrypoint.module`, `entrypoint.class`; tùy chọn `authors`, `min_core_version` (mặc định `0.1.0`).
- `[[operations]]`: `name`, `input`, `output`, `side_effects` ∈ `none | local_write | external` (mặc định `none`).
- `[permissions]`: `fs_read[]`, `fs_write[]`, `network`, `exec[]`, `cloud_ai`. `[adapters]`: `cli`=true, `mcp`=true, `rest`=false, `events`=false. `[dependencies.licenses].allowed[]`.
- Khóa không có trong schema → lỗi. TOML hỏng hoặc sai schema → `invalid_input`; file không có → `not_found`.
- Code: `core/manifest.py` · Test: `test_manifest.py`.

### FR-05 Discovery plugin — Roadmap 0.3

- Quét entry point nhóm `lfmap.plugins`; class phải là subclass `Tool`; manifest đọc qua `importlib.resources` cạnh module của class.
- Tập operation khai báo trong manifest phải bằng tập `@operation` của class.
- Tên entry point phải bằng `plugin.id`; đăng ký trùng id → lỗi.
- Plugin hỏng (`ImportError`, `TypeError`, `ToolError`) bị bỏ qua, ghi warning `Skipping plugin <name>: ...`; các plugin khác vẫn chạy.
- `Registry.get(id)` không có → `not_found`; `Registry.all()` sắp theo id.
- Code: `core/registry.py` · Test: `plugins/lfmap-echo/tests/test_tool.py::test_discovered_through_entry_point`, `test_manifest_matches_tool`.

### FR-06 CLI sinh tự động — Roadmap 0.4

| Lệnh | Hành vi |
|---|---|
| `lfmap plugins list [--json]` | Mỗi dòng `id  version  op1, op2`; `--json` in mảng `{id, version, operations}` |
| `lfmap <plugin> <operation> --field value ...` | Mỗi field của Input thành option `--field-name` (`_` → `-`); `bool` thành `--x/--no-x`; field không có default là bắt buộc |
| `lfmap <plugin> <operation> --input-json '{...}'` | Dùng khi Input có field không phẳng (không phải str/int/float/bool/Path/Literal/Optional của chúng) |
| `--json` | In Output dạng JSON (indent 2); mặc định in `key: value` |
| `--yes`/`-y` | Bỏ qua xác nhận tác dụng phụ |
| `lfmap serve mcp [--plugins id ...] [--approve plugin.op ...]` | Chạy MCP server stdio (FR-07) |

- Plugin có `adapters.cli = false` không sinh lệnh.
- Mã thoát: 0 thành công; 1 `ToolError`, `ValidationError`, JSON hỏng (stderr `Error [code]: message`); 2 lỗi bất ngờ (`Error [internal]`) hoặc lỗi cú pháp lệnh của Typer/Click.
- Code: `core/cli.py` · Test: `test_cli.py`.

### FR-07 MCP adapter sinh tự động — Roadmap 0.5

- Tên tool `<plugin>_<operation>`, `-` đổi thành `_`, phải khớp `^[a-zA-Z0-9_-]{1,64}$` (ADR-014), sai → `invalid_input`.
- Input schema sinh từ các field của Input model (keyword-only, giữ default); output có cấu trúc (`structured_output=True`) theo Output model.
- Annotation: `readOnlyHint = (side_effects == none)`, `openWorldHint = (side_effects == external hoặc permissions.network)`.
- Mô tả = dòng đầu docstring; có tác dụng phụ thì thêm `Side effects: <x>. Approved by the user for this server.` hoặc `Requires approval when the server starts.`
- `--plugins` lọc plugin (id không có → `not_found`); plugin có `adapters.mcp = false` không sinh tool.
- Lỗi `ToolError` trả về MCP error `"<code>: <message> <details>"`.
- Trong lúc chạy tool, stdout chuyển sang stderr.
- Server name `lfmap`, version = `lfmap_core.__version__`, instructions liệt kê plugin.
- Code: `core/mcp_adapter.py` · Test: `test_mcp_adapter.py`.

### FR-08 Phê duyệt tác dụng phụ — Roadmap 0.5/0.6, ADR-009

- CLI: `side_effects ≠ none` → `typer.confirm(...)`, từ chối → abort; `--yes` bỏ qua.
- MCP: `side_effects ≠ none` và chưa `--approve <plugin>.<op>` → lỗi `permission_denied: ... start the server with --approve ...`.
- `--approve` tên không tồn tại → server không khởi động (`invalid_input`); `--approve` cho operation `external` → không khởi động (`invalid_input`).
- Code: `core/cli.py::_operation_command`, `core/mcp_adapter.py::_make_tool`, `_check_approvals` · Test: `test_cli.py::test_nested_input_uses_json_and_confirms`, `test_mcp_adapter.py::test_side_effects_*`, `test_unknown_approval_refused`, `test_external_cannot_be_pre_approved`.

### FR-09 Cấu hình người dùng — Roadmap 0.6

- Đường dẫn: `LFMAP_CONFIG` nếu có, ngược lại `%LOCALAPPDATA%\lfmap\config.toml` (thiếu `LOCALAPPDATA` thì `~\AppData\Local`).
- File không có → cấu hình rỗng; TOML hỏng → `invalid_input`.
- `[paths]`: giá trị là chuỗi hoặc mảng chuỗi, khác → `invalid_input`.
- Biến dựng sẵn `data_dir`, `temp_dir`; `temp_dir` được tạo nếu chưa có.
- Code: `core/config.py` · Test: `test_config.py`.

### FR-10 Permission Manager — Roadmap 0.6, ADR-009

- `from_manifest(perms, variables)`: mở rộng `${name}` (mảng → nhiều root; biến lồng trong chuỗi được); biến chưa định nghĩa → root rỗng + warning; root không tuyệt đối → `invalid_input`; root (trước hoặc sau `realpath`) là đường dẫn mạng → `permission_denied`.
- Root ghi cũng là root đọc; root đọc không ghi được.
- `require_read(path)`, `require_write(path)` trả `Path` đã `realpath` khi hợp lệ; từ chối (`permission_denied`) khi: đường dẫn mạng/thiết bị (`\\`, `//`, `\??\`, gồm `\\?\`, `\\.\`); ngoài root; dùng `..` thoát ra; tên trùng tiền tố (`D:\Docs2` với root `D:\Docs`); symlink/junction trỏ ra ngoài. So sánh không phân biệt hoa thường trên Windows.
- `require_network()` → `permission_denied` khi manifest `network = false`.
- Code: `core/permissions.py` · Test: `test_permissions.py`, `test_config.py::test_network_path_in_config_refused`.

- Code: `plugins/lfmap-echo/src/lfmap_echo/__init__.py`, `core/runtime.py::default_context` · Test: `plugins/lfmap-echo/tests/test_tool.py`.

- Operation `say(SayInput{text, upper=False}) -> SayOutput{text, length}`; `upper` → viết hoa. Không tác dụng phụ, không quyền.
- Code: `plugins/lfmap-echo/` · Test: `plugins/lfmap-echo/tests/test_tool.py`; CI smoke test.

### FR-13 Kiểm tra giấy phép dependency — Roadmap 0.7, ADR-010

- Danh sách cho phép = hợp các `[dependencies.licenses].allowed` trong `plugins/*/src/*/lfmap.toml`.
- Đọc `License-Expression`, nếu không có thì classifier `License ::`, rồi trường `License` ngắn; chuẩn hóa bí danh (vd `MIT License` → `MIT`).
- Biểu thức `AND`: mọi phần phải được phép. Không khai báo → `WARN`. Không khớp → `FAIL`, script trả mã 1.
- Bỏ qua package trong workspace và `EXCEPTIONS` (`cffi`).
- Chạy trên môi trường `uv sync --no-dev` (chỉ dependency runtime).
- Code: `scripts/check_licenses.py`, `.github/workflows/ci.yml`.
