# LFMAP Phase 0 — Hướng dẫn sử dụng (UG)

Phiên bản 1.0 · 2026-10-19 · Áp dụng cho lfmap-core 0.1.0 (mốc `f63f0ee`). Shell: PowerShell 7.

## 1. Cài đặt

Yêu cầu: Windows, Git, [uv](https://docs.astral.sh/uv/) (DIEP-ANH: uv 0.13.1). uv tự cài Python 3.12 nếu chưa có.

```powershell
git clone https://github.com/hungnp1999/lfmap D:\Development\lfmap
Set-Location D:\Development\lfmap
uv sync              # tạo .venv, cài lfmap-core, lfmap-echo và công cụ dev
uv run pytest        # kiểm tra: toàn bộ test phải pass
```

## 2. Dùng CLI

```powershell
uv run lfmap --help
uv run lfmap plugins list                    # echo  0.1.0  say
uv run lfmap plugins list --json
uv run lfmap echo say --help
uv run lfmap echo say --text "xin chào"      # text: xin chào / length: 8
uv run lfmap echo say --text "xin chào" --upper --json
```

Quy ước chung cho mọi plugin:

- Lệnh: `lfmap <plugin> <operation>`; mỗi trường input là một option `--ten-truong`; trường kiểu bool có cặp `--x/--no-x`.
- Operation có input lồng (danh sách, object) nhận `--input-json '{"names": ["a","b"]}'`.
- `--json` in kết quả JSON; mặc định in `key: value`.
- Operation có tác dụng phụ hỏi `Continue? [y/N]`; `--yes` hoặc `-y` để bỏ qua (chỉ dùng trong script đã tin cậy).
- Mã thoát: `0` thành công, `1` lỗi nghiệp vụ hoặc input sai (dòng `Error [code]: ...` trên stderr), `2` sai cú pháp lệnh hoặc lỗi bất ngờ.

## 3. Cấu hình thư mục được phép

Plugin chỉ đọc/ghi được thư mục anh khai báo. Tạo file `%LOCALAPPDATA%\lfmap\config.toml`:

```powershell
New-Item -ItemType Directory -Force "$env:LOCALAPPDATA\lfmap" | Out-Null
notepad "$env:LOCALAPPDATA\lfmap\config.toml"
```

```toml
[paths]
documents = ['D:\Docs', 'E:\Scans']   # dùng làm ${documents} trong manifest
exports = 'D:\Docs\_markdown'
```

- Dùng chuỗi nháy đơn để khỏi phải nhân đôi `\`.
- Chỉ đường dẫn tuyệt đối trên máy; `\\server\share` bị từ chối.
- `${data_dir}` (`%LOCALAPPDATA%\lfmap\<plugin>`) và `${temp_dir}` có sẵn.
- Muốn dùng file cấu hình khác (thử nghiệm): `$env:LFMAP_CONFIG = 'D:\tmp\lfmap-test.toml'`.

## 4. Dùng với Claude (MCP)

Đăng ký một lần với Claude Code:

```powershell
claude mcp add lfmap -- uv run --directory D:\Development\lfmap lfmap serve mcp --plugins echo
claude mcp list        # lfmap: ... Connected
```

Nếu Claude không tìm thấy `uv`, dùng đường dẫn đầy đủ tới `uv.exe` (`(Get-Command uv).Source`).

- Mỗi operation thành tool `<plugin>_<operation>`, ví dụ `echo_say`.
- Operation có tác dụng phụ bị từ chối qua MCP, trừ khi anh duyệt lúc khởi động server: `lfmap serve mcp --plugins markitdown --approve markitdown.export`. Operation `external` (gửi ra ngoài máy) không duyệt trước được.
- `--plugins` bỏ trống = mọi plugin đã cài.

## 5. Dùng như thư viện Python (SDK)

```python
from lfmap_echo import SayInput, say

print(say(SayInput(text="xin chào", upper=True)))   # text='XIN CHÀO' length=8
```

SDK chạy với quyền rỗng: operation cần file phải chạy qua `lfmap_core.runtime.run_operation` để nhận quyền từ `config.toml`.

## 6. Viết plugin mới (tóm tắt)

1. Copy `plugins/lfmap-echo` thành `plugins/lfmap-<ten>`, đổi tên package `lfmap_<ten>`.
2. `schemas.py`: Input/Output Pydantic, mỗi field có `description`.
3. `tool.py`: `class XTool(Tool)`, method `@operation("ten")` nhận một Input, trả một Output; lỗi nghiệp vụ dùng `ToolError(code, message, details)`; mọi đường dẫn từ input đi qua `self.ctx.permissions.require_read()` / `require_write()` trước khi mở file.
4. `lfmap.toml`: khai báo `[[operations]]` (tên khớp `@operation`, `side_effects` đúng), `[permissions]`, `[dependencies.licenses]`.
5. `pyproject.toml`: `[project.entry-points."lfmap.plugins"] <id> = "lfmap_<ten>.tool:XTool"`; thêm vào `[tool.uv.sources]` và `dependencies` của root nếu cần.
6. `uv sync` → `uv run lfmap plugins list` phải thấy plugin → viết test → PR.

Đặc tả đầy đủ: `02_Plugin_Contract.md`.
