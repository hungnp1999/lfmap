## Thiết kế

Chi tiết trong spec. Tóm tắt:

```text
plugin (events = true) ── ctx.events.publish("knowledge.indexed", {...}) ─┐
lfmap jobs run ── bus.publish("markitdown.convert.requested", {"input":…}, source="core")
                                                                          ▼
                       %LOCALAPPDATA%\lfmap\events.db (SQLite WAL)
                       events ─< deliveries >─ subscriptions (bền, có tên)
                                                                          │
lfmap events run / cuối jobs run ── drain(): claim (lease 60 s) → handler → ack | retry (lùi) | dead
                                                                          │
adapter-<plugin> (pattern <plugin>.*.requested) ── run_operation(channel="event")
     ├─ tier ≤ [events] max_tier ── chạy ── publish .completed {request_id, output}
     ├─ vượt trần ── đề xuất approvals (job = "events") ── lfmap approvals approve (TTY)
     └─ ToolError ── publish .failed {request_id, error}
```
