### API đã chốt (`packages/lfmap-core/src/lfmap_core/jobs_doctor.py`)

```python
@dataclass(frozen=True)
class Check:
    name: str
    ok: bool | None
    detail: str
    fix: str = ""


def run_checks(registry: Registry, path: Path | None = None) -> list[Check]: ...
def _run(args: list[str]) -> str: ...  # stdout; ToolError backend_unavailable / internal
def _http_get(url: str, timeout: float) -> str: ...  # raises OSError when unreachable
```

- Gọi `jobs.find_uv()`, `jobs.load_jobs()`, `jobs.QUERY`, `jobs.registered_tasks()` qua module `jobs` (test vá `jobs.find_uv`). Không viết lại luật tìm uv.
- `ok = None` nghĩa là "cảnh báo hoặc không xác định". Chỉ `False` làm exit 1.
- CLI: `lfmap jobs doctor [--json]`. Bảng mỗi dòng: tên, `ok`/`warn`/`FAIL`, detail, fix. `--json` in danh sách `{name, ok, detail, fix}`. Exit 1 nếu có `False` (dùng `typer.Exit(1)`, không ném ToolError).

### Bảy kiểm tra, theo thứ tự

| Tên | `True` | `None` | `False` |
|---|---|---|---|
| `uv` | `find_uv()` tìm được | | không tìm được; fix: cài uv |
| `jobs_file` | đọc được, mọi plugin/operation tồn tại | không có `jobs.toml` | lỗi TOML/schema, hoặc job trỏ tới plugin/operation không có (liệt kê id) |
| `tasks` | task `\LFMAP\` khớp đúng các job bật | không có `schtasks`; hoặc không job, không task | thiếu task cho job bật, hoặc còn task của job tắt/đã xóa; fix: `uv run lfmap jobs register` |
| `logon_mode` | mọi task có `LogonType` `Password` hoặc `S4U` | có task `InteractiveToken` ("chỉ chạy khi đã đăng nhập"); hoặc không có task | (không bao giờ) |
| `wake` | sleep AC = 0, hoặc mọi task có `<WakeToRun>true` | không có task hoặc không có `schtasks` | máy có ngủ và có task thiếu WakeToRun (liệt kê id) |
| `sleep` | AC = 0 (không ngủ) | AC > 0 (ghi số phút), hoặc không đọc được | (không bao giờ) |
| `ollama` | `GET http://localhost:11434/api/version` (2 giây) trả lời, ghi version | không job bật nào dùng plugin có `permissions.network = true` | cần mà không gọi được; fix: mở Ollama |

Chỉ đọc XML của task thuộc job **đang bật** và đã đăng ký: `schtasks /Query /TN \LFMAP\<id> /XML`.

### Quyết định nhỏ chốt trong kế hoạch này

| # | Quyết định | Lý do | Phương án đã loại |
|---|---|---|---|
| 1 | `InteractiveToken` là cảnh báo (`None`), không phải `False` | Task vẫn chạy khi màn hình khóa nếu Hùng còn đăng nhập, đủ cho Exit 1.8. Sửa cần mật khẩu Windows, CLI không nhận (quyết định #6) | Coi là `False`: doctor không bao giờ xanh nếu chưa nhập mật khẩu |
| 2 | Kiểm Ollama khi có job bật dùng plugin `network = true` | Manifest chưa có trường "dùng Ollama"; thêm trường là đổi Plugin Contract, ngoài phạm vi | Thêm `permissions.ollama`; hoặc luôn kiểm (báo lỗi giả trên máy không cần Ollama) |
| 3 | Đọc sleep AC = giá trị `0x…` **áp chót** của `powercfg` | Không phụ thuộc ngôn ngữ Windows; các dòng Min/Max cũng có `0x` nên không lấy giá trị đầu | Tìm chuỗi "Current AC Power Setting Index" (hỏng trên Windows không phải tiếng Anh) |
| 4 | Task của job tắt hoặc đã xóa là `False` | Task đó chạy và thất bại mỗi lần; `register` tự xóa | Chỉ cảnh báo |
| 5 | Không có `schtasks`/`powercfg` (Linux, CI) cho `None` | Doctor vẫn chạy được ở mọi nơi; test Cloud không cần Windows | Báo `False` |

### Không được

- Đổi bất kỳ thiết lập nào. Chỉ `schtasks /Query` và `powercfg /query` (test `test_doctor_only_reads` kiểm).
- Cần quyền admin, thêm dependency (dùng `urllib.request`, `re`, `xml` hoặc regex của thư viện chuẩn).

## 3. Task B: chạy thật trên DIEP-ANH qua Remote Control

Làm sau khi PR task A merge. Hùng mở một thread trong project (hoặc nhắn trong thread này), Claude chạy trên DIEP-ANH. Lệnh có tác dụng phụ (`register` thật, đổi thiết lập nguồn) chỉ chạy khi Hùng duyệt trong chat.

```powershell
cd D:\Development\lfmap
git switch main; git pull                 # main checkout is still on feature/knowledge-k4-k7: check it is clean first
uv sync                                   # if lfmap.exe is locked by the Claude app, report it; do not kill processes
Get-Content "$env:LOCALAPPDATA\lfmap\jobs.toml"   # echo-hello from the J1+J2 check should be there
uv run lfmap jobs doctor                  # expected now: tasks False (nothing registered yet)
uv run lfmap jobs register --dry-run
uv run lfmap jobs register                # NEEDS Hùng's OK in chat; only touches \LFMAP\
uv run lfmap jobs doctor
```

Thử chạy khi máy khóa (Exit 1.8), không cần ngồi trước máy: đổi tạm `echo-hello` sang `schedule = { every_minutes = 5 }`, `register`, khóa máy bằng `rundll32.exe user32.dll,LockWorkStation` (cần Hùng duyệt), đợi một chu kỳ rồi xem `Get-Content "$env:LOCALAPPDATA\lfmap\logs\jobs-$(Get-Date -Format yyyy-MM-dd).jsonl" -Tail 3`. Xong thì trả lịch về `daily = "07:30"` và `register` lại.

Lưu ý: nếu DIEP-ANH ngủ, Remote Control mất kết nối và job lỡ giờ. Doctor sẽ báo `wake` `False` khi sleep AC > 0. Cách sửa từ xa: `powercfg /change standby-timeout-ac 0` (đổi thiết lập hệ thống, cần Hùng duyệt rõ). Cách giữ nguyên chế độ ngủ: bật "Wake the computer to run this task" trong Task Scheduler (task C).

## 4. Task C: Hùng làm tại DIEP-ANH (không chặn Exit)

- Muốn job chạy cả khi đã đăng xuất: Task Scheduler > `\LFMAP\echo-hello` > General > "Run whether user is logged on or not", nhập mật khẩu Windows. Doctor chuyển `logon_mode` từ `warn` sang `ok`.
