## Bối cảnh

Phase 1 của Roadmap cần hạng mục 1.4 (catalog và tìm kiếm tài liệu local) và 1.5 (MCP cấp đoạn trích có trích dẫn cho Claude). Đây là điều kiện Exit của Phase 1: hỏi Claude trên một thư mục PDF/DOCX và nhận câu trả lời có trích dẫn, dữ liệu chỉ rời máy ở mức đoạn được truy xuất.

Đã xong trước bàn giao này:
- lfmap-core 0.2.0: config, phê duyệt theo tầng, audit, grants, `ctx.data_dir`/`settings`/`channel`.
- Plugin markitdown (1.1), mà knowledge gọi để trích nội dung.
- TC-K0 spike trên DIEP-ANH: đạt.
- TC-K1 đến K3 (khung package, `store.py`, `scanner.py`) do qwen viết; PR đang chờ CI.

Làm bây giờ vì 1.1 đã đóng, và mỗi lúc chỉ chạy một luồng Claude nặng (gói Pro).

## Mục tiêu

`lfmap knowledge reindex` và `lfmap knowledge search "..."` chạy được trên thư mục thật. Claude Code gọi được `knowledge_get_context` qua MCP và nhận đoạn trích có `citation.path` và `heading_path`.

Tiêu chí hoàn thành là Definition of Done ở spec mục 9. Kiểm tra được bằng:
- Reindex lần hai không trích hay embed lại file nào.
- Xóa `vectors/` rồi reindex thì top-5 không đổi.
- 10.000 file reindex lần hai dưới 60 giây.
- Root `secret` không bao giờ ra MCP.
- Không có kết nối nào ngoài loopback.

## Thiết kế

Xem spec mục 3 (lưu trữ), 4 (thuật toán reindex) và 5 (thành phần). Tóm tắt luồng:

```text
reindex: writer_lock → scanner.reconcile (K3) → extract (K4, gọi markitdown, cache md theo hash)
         → chunker (K5) → fts.index_chunks (K6) → embed (K7, Ollama loopback) → vectors.upsert (K8)
         → edges (K13) → GC → optimize()
search:  fts.keyword_search + vectors.search → RRF → lọc sensitivity theo channel → egress_log (K10)
get_context: search hybrid → cắt theo token_budget → untrusted=True + citation (K11)
```

`tool.py` chỉ do Claude Code sửa, kể cả khi card là của qwen, để tránh xung đột giữa các card cùng sửa file này. qwen chỉ viết module thuần (`extract.py`, `chunker.py`, `fts.py`, `embed.py`, `catalog.py`).

## Rủi ro và điểm cần lưu ý

- **qwen viết test sai, hoặc tự tạo fixture.** Test do Claude Code viết sẵn; qwen chỉ viết code.
- **Rò dữ liệu qua MCP** (root `secret`, `egress_log` thiếu). K10 là task bắt buộc Claude review, có test riêng.
- **Prompt injection từ tài liệu.** Chỉ giảm nhẹ được bằng `untrusted=True` và mô tả trong docstring. Không hứa nhiều hơn.
- **Tìm tiếng Việt không dấu khớp lẫn** ("ma" khớp "mà/má/mã"). Đo trên tài liệu thật ở K14.
- **Khóa file trên Windows.** `lfmap.exe` có thể đang bị MCP server giữ, nên đóng app Claude trước `uv sync`.
- **Quyền đọc:** knowledge gọi markitdown bằng quyền của chính nó, nên markitdown đọc được mọi thứ trong `${knowledge}` (spec 7.7).
  - Đúng thiết kế. Nếu Hùng muốn hẹp hơn thì phải đổi trước K4.
