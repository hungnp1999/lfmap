Plugin `llm` (`plugins/lfmap-llm`, #189, task MC-3): operations `summarise`, `extract` and `classify` send text to the model the owner routed each task to (`ctx.models`), usable from CLI, MCP and as flow steps (`call = "llm.summarise"`). `Tool.call_tier` makes a local route T0 and a cloud route T3 (ADR-020). Prompts are fixed, the input sits after a delimiter and is declared data; `extract` keeps only schema keys of the declared type and `classify` only a given label, anything else is `backend_unavailable` (`bad_response`). The plugin writes no files and names a task, never a URL. No new dependency.
