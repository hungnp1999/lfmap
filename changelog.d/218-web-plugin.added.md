Plugin `web` (`plugins/lfmap-web`, #218, task WEB-2): operation `fetch` reads one public HTTPS page from a host in the owner's `[web] allowed_hosts` through `ctx.web`, usable from CLI, MCP and as a flow step (`call = "web.fetch"`). It is T0 on every channel; `Tool.call_tier` makes a URL whose query is longer than 200 characters T3, so it never runs unattended. Page text is returned verbatim and never interpreted; `save = true` writes a copy to `data_dir/pages/` named by UTC time, host and `sha256[:8]`. The plugin has no network code and no new dependency.
