`ModelRouter` and `ctx.models` (#189, MC-2): plugins with `[adapters] models = true` call `ctx.models.chat(..., task=...)` / `embed(..., task=...)`; the router routes the task through `[models]`, refuses `secret` data and `embed` to a cloud endpoint, requires `cloud_ai` and `network` in the manifest, gates every cloud call at T3 and writes `model_call` lines (`sent`, then the result) to `audit.jsonl` with allow-listed fields only. Local calls write no line. No plugin uses it yet.
