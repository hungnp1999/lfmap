Changelog fragments: each pull request adds `changelog.d/<slug>.<category>.md` instead of editing `CHANGELOG.md`, so open PRs no longer conflict on the changelog (a conflicting PR gets no CI run from GitHub). `scripts/changelog_fragments.py check` validates them and `release X.Y.Z` writes them into `CHANGELOG.md` and deletes them. Entries already under `[Unreleased]` stay until the first release. Standard library only, no new dependency.
