`lfmap data classes | explain | classify | unclassify` and two `lfmap jobs doctor` checks (#197 DC-4, ADR-025): `classify` and `unclassify` edit only the one line in `[data.classes]` (comments and other tables stay byte for byte, the new text is validated before `os.replace`) at an interactive terminal only; a change that lowers the class of the path needs the owner code, raising needs a yes/no, and each is audited as `data classify|unclassify <old> -> <new>`.
