`lfmap doctor` has a read-only `security` group (#198): whether Microsoft Defender real-time protection is on, whether Controlled Folder Access is on and covers the folders in `[paths]`, `[backup] folder` and `%LOCALAPPDATA%\lfmap`. It runs one fixed `Get-MpComputerStatus` / `Get-MpPreference` PowerShell script from System32, only warns (never changes the exit code, never changes a setting) and is skipped outside Windows. No new dependency.
