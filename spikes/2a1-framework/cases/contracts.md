- `lfmap_core` exports only `ErrorCode`, `OperationSpec`, `Tool`, `ToolContext`, `ToolError`, `invoke` and `operation`. `ExtractResult`, `SkipResult` and `Chunk` are not there: each module defines its own dataclasses, and the tests import them from that module.
- `ToolError(code, message, details=None)` stores `self.details = details or {}`: `details` is always a dict, never `None`, so `"reason_code" in e.details` and `e.details.get(...)` are safe. `code` is one of `invalid_input`, `permission_denied`, `not_found`, `backend_unavailable`, `timeout`, `internal`.
- `PermissionManager.require_read(path)` and `require_write(path)` return the resolved `Path` and raise `ToolError("permission_denied")` for a path outside the allowed folders or a UNC/device path; they never return a flag. `require_network()` returns `None` and raises `ToolError("permission_denied")` when network access is not declared.
- Standard library: `ipaddress.ip_address(text)` raises `ValueError` (not `TypeError`) for text that is not an IP address; `json.JSONDecodeError` is a `ValueError`; `urllib.error.URLError` and `TimeoutError` are `OSError` subclasses.
